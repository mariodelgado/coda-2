DiagramsHow language becomes physics

Six mid-century plates. Each figure has a caption and a short explanation. A CEO or engineer can read each once. The visual language matches the cover: seafoam, olive, translucent blues, one red accent, extended sans, geometric clarity.

These plates restate the system claim without dark UI chrome. Natural language becomes typed decisions. Decisions become numbers. Numbers cross a narrow adapter firewall into replaceable physics. Fidelity and traces flow back into an instrument. The stage (physics) stays above the dock (agency).

PLATE 01The whole machine — intent to instrument, with fidelity back.

An operator states a goal. An agent maps it onto five tools and emits traces. The adapter is the waist: only six typed methods reach the backend. The backend may be the noisy simulator (default) or a hardware-shaped stub. Results — fidelity, detuning, readiness — return into the instrument UI. The human can see whether the loop worked. The dashed red arc is the product feedback path.

PLATE 02Closed-loop calibration — measure, decide against 0.88, apply, remeasure.

Calibration is viable as an agent tool only because it is a loop. Measure fidelity. Decide whether best fidelity has crossed the service threshold (0.88) or whether to sample a neighbor. Apply an update through the adapter (this samples interface latency). Remeasure. Exit on success, exhausted iterations, or a demo fidelity cap. Hardened calibration (PR #2) widens the sim kernel and strengthens early exploration. Founder-demo seeds converge. The adapter seam does not change.

PLATE 03Language → decisions → numbers → contract → physics. Firewall at the adapter.

Prose stops at the red bar. The planner (deterministic by default; optional LLM behind CONDUCTOR_ENABLE_LLM) turns a goal into ToolCalls. Tools produce numbers — qubit ids, parameter deltas, thresholds. Only those typed payloads cross the QPUAdapter. That firewall lets backends swap without rewriting the agent. It also stops the agent from inventing illegal pulse calls.

PLATE 04Stage holds physics; dock holds agency. On current main the stage is three panes — drift | device 3D | cryostat — with two resizable splitters. No tabs.

Chat is a fine composer. It is a poor primary surface for a drifting device. The instrument keeps continuous state in the visual field. The stage shows three panes at once. Left: a high-contrast drift grid, coplanar with the fidelity surface, with true/applied markers. Center: the 3D device (qubits, chiplets, resonators) with a readout card for fidelity, T1, T2, and mK. Right: the isometric dilution-fridge plate with a status strip and the state chip. Two iPadOS Split View–style separators, with capsule handles on hover, resize the panes. There is no glass inset and no tab flip. PR #2 first used tabs labeled drift | device. That control is past. The device and cryostat panes are UI. They are not a fridge sensor. The dock over the bottom-third frost holds the transcript, workflow chips, and composer — agency under physics, not instead of it. See FIG. A.0 for the live screenshot.

PLATE 05The three founder-facing dials: time-to-cal, success rate, interface latency.

If calibration is a product, its cost must be observable. Time-to-calibrated is wall seconds from loop start to best fidelity ≥ threshold (successes only). Calibration success rate is successes over attempts. Interface latency is the seconds per apply_calibration_update roundtrip. CalibrationService owns the aggregates. The HTTP /metrics surface rolls percentiles for operators and demos.

PLATE 06Real software artifact versus the stand-in noisy simulator.

Keep the left column. The adapter contract, calibration loop, orchestrator traces, FastAPI plane, and instrument UI (including the 3D device panel) are the durable artifact. The right column is honest scaffolding: a toy 1–2 qubit model with hidden true parameters, random-walk drift, and a climbable fidelity kernel — not a fridge, not an AWG, not a pulse compiler. A shaped stub documents the driver shape and refuses real work. Replace the stand-in behind the same six methods.
